# Youbot Shorts Clipper (Home Assistant add-on)

Automatically turns trending YouTube videos into vertical Shorts — the most
replayed ≤40s moment on top, copyright-free GTA mega-ramp gameplay on the
bottom half (no black bars). A simple web gallery shows every clip it has made,
with a single **Start** button.

See [DOCS.md](DOCS.md) for options and details.
