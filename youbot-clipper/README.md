# Youbot Shorts Clipper (Home Assistant add-on)

Automatically turns podcast episodes into vertical Shorts — an engaging 20–40s
moment on top, copyright-free GTA mega-ramp gameplay on the bottom half (no
black bars). It works through a list of podcast channels newest-to-oldest,
picking moments with OpenAI, and never repeats an episode. A web gallery shows
every clip it has made, with a single **Start** button.

See [DOCS.md](DOCS.md) for options and details.
